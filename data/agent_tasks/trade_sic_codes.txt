roofing (domestic)
43910, Roofing activities, roofing (domestic)
Companies House label: Roofing activities.
ONS class 43.91 Roofing activities. This class includes: erection of roofs; roof covering. This class excludes: renting of construction machinery and equipment without operator, see 77.32.
This is the dedicated roofing code. It is not limited to domestic work.

fitted kitchens
43320, Joinery installation, fitted kitchens
Companies House label: Joinery installation.
ONS class 43.32 Joinery installation. This class includes: installation of doors (except automated and revolving), windows, door and window frames, of wood or other materials; installation of fitted kitchens, built-in cupboards, staircases, shop fittings and the like; interior completion such as ceilings, movable partitions, etc.
There is no SIC limited to fitted-kitchen showrooms or kitchen fitters alone. 43320 is the class whose official notes name installation of fitted kitchens. It is only a partial match because the same class also covers doors, windows, staircases, shop fittings and other interior completion.
31020, Manufacture of kitchen furniture, is manufacture of kitchen furniture, not fitting or retailing kitchens, so it is not used as the trade code.

conservatories/orangeries
No dedicated SIC code. The ONS explanatory notes do not name conservatories or orangeries.
Closest official codes, each only a partial match:
43342, Glazing, conservatories/orangeries
Companies House label: Glazing.
ONS subclass 43.34/2 Glazing. This subclass includes: installation of glass, mirrors, etc. This subclass excludes: installation of glazed window units and installation of unglazed window frames, see 43.32.
Partial because a conservatory or orangery is a structure (base, frame, roof and glazing), not only installation of glass, and the subclass itself sends glazed window units to 43.32.
43320, Joinery installation, conservatories/orangeries
Official notes include installation of windows, doors and frames, and do not name conservatories. Partial for the frame and glazing only.
41202, Construction of domestic buildings, conservatories/orangeries
Companies House label: Construction of domestic buildings.
ONS subclass 41.20/2 includes construction of residential buildings and remodelling or renovating existing residential structures. Group 41.2 says: if only specialised parts of the construction process are carried out, the activity is classified in division 43. Partial, and the wrong code for a specialist installer who does not construct complete residential buildings.
43910, Roofing activities, conservatories/orangeries
Partial only where the work is the roof. See the roofing note above.
