# Product changelog

Canonical: https://ideas.gohighlevel.com/changelog

This tracks UI/product feature changes (new workflow actions, new calendar
options, new AI features, etc.) — distinct from `api/CHANGELOG.md`, which
tracks the developer API surface. HighLevel ships product changes
continuously, so treat `product/FEATURE_MAP.md` and the other `product/*.md`
docs in this pack as a navigation aid frozen at the time they were written,
not as current truth. Check this changelog when a client reports something
in the UI that doesn't match what's documented here.
