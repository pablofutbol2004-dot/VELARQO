# First 30 days — learning sequence

Do this in order. The point is to collapse uncertainty, not build infrastructure.

## Week 1 — acquisition + customer truth
- launch first 2×2 email experiment;
- get 5–10 installer conversations;
- capture real funnel/economic numbers;
- request 3 redacted exports;
- record every objection verbatim;
- classify legal entity / outreach data quality issues.

**Do not:** build portal, content calendar, second niche, autonomous sales agent.

## Week 2 — offer/data proof
- finish 10 conversations;
- inspect exports + collection flows;
- choose first pilot client based on list quality and operational responsiveness, not charisma;
- freeze v0 qualified-booking definition;
- sign commercial/data terms;
- configure 100–250 contact micro-pilot.

## Week 3 — deliver manually enough to learn
- launch canary batch;
- inspect every homeowner reply;
- tag categories/lost reasons;
- only automate stable routine replies;
- measure time per qualified booking;
- expand batch only if delivery/compliance healthy.

## Week 4 — economics + proof
- reconcile booked/attended/quoted/won;
- client interview: quality vs their normal leads;
- calculate revenue/contact and cost/result;
- write first case study only from verified numbers;
- update price and qualification rules;
- decide whether constraint is acquisition, delivery, data eligibility, client operations, or economics.

## End-of-month decision
Choose exactly one:
1. **double down** — loop works; add volume;
2. **repair** — one identifiable bottleneck is fixable;
3. **change offer/result** — niche need exists but commercial unit is wrong;
4. **change niche** — structural data/economics/compliance problem;
5. **kill model** — evidence says effort is better spent elsewhere.

Do not declare success from replies or bookings alone. The chain must work end to end.
