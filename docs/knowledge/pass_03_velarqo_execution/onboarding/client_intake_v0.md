# Client onboarding intake v0

## Company
- legal name
- trading name
- Companies House number
- website
- primary contact
- billing contact
- service areas/postcodes
- products included/excluded
- office hours
- calendar owners

## Economics
- average order value
- approximate gross contribution or acceptable acquisition cost
- enquiries/month
- quotes/month
- wins/month
- current lead sources
- current lead/appointment spend

## Data
- source systems
- estimated old quote count
- oldest record
- fields available
- export method
- redacted sample received
- third-party/bought data present? yes/no
- current customers mixed in? yes/no

## Compliance provenance
- how contact details were collected
- original forms/scripts/screenshots supplied
- opt-out language at collection supplied
- existing consent/marketing flags
- suppression/opt-out file
- client attestation on data provenance

## Campaign
- sender identity
- reply-capable phone number/email
- offers/messages client can truthfully honour
- qualification criteria
- appointment duration
- capacity/week
- booking calendar
- reminder process
- escalation contact

## Commercial
- billable result definition
- no-show/cancellation rules
- attribution window
- duplicate handling
- payment timing
- reporting cadence
- termination
- DPA / data terms

## Technical launch tests
- test email/SMS delivered
- replies received
- opt-out suppression works
- calendar booking works
- attribution ID persists
- client gets notification
- result can be marked attended/quoted/won
