# Business Knowledge Pass 03 — Velarqo Execution Pack v0

Built: 2026-09-30

This is the **application layer** on top of Pass 01 (durable business playbooks) and Pass 02 (verified P0 truth). Everything here is deliberately launchable but **versioned as v0**: scripts and prices are hypotheses to test against reality, not doctrine.

## Objective
Get from “we have researched database reactivation” to:

**cold prospect → qualified installer conversation → lawful usable list → bounded campaign → qualified booked surveys → attribution → invoice → case study → iteration**

## Default commercial hypothesis
- Niche: UK homeowner-facing window & door installers.
- Core result: **qualified booked survey**.
- Risk reversal: no setup fee; pay only for valid booked surveys; genuine no-show gets a credit/replacement.
- Founder-pilot test price: **£75 per qualified booked survey** for the first 1–2 proof clients. This is a **TEST PRICE**, not market truth.
- Client approves messages before launch.
- Start with a micro-batch before scaling the eligible list.

Why £75 for the first proof clients? A current fresh-window appointment supplier publicly starts around £130/booked appointment, so £75 is intentionally below that outside option while Velarqo has no case study. If recovered appointment quality proves strong, raise it rather than anchoring permanently low.

## Files
- offer: exact pilot and qualification definition
- outbound: cold-email experiment and reply routing
- sales: discovery call + objections
- onboarding: intake and launch checklist
- delivery: reactivation sequences + reply handling
- reporting: attribution, weekly client report, founder KPI board
- commercial: terms checklist
- data: canonical schemas
- experiments: first-30-day learning plan

## Rule
Do not automate a step merely because it can be automated. Automate it after the manual loop shows it is repeated, stable, and valuable.
