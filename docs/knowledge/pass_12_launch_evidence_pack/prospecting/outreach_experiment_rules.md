# Acquisition experiment rules

Treat outbound as a measurable funnel, not a copywriting contest.

Track:
`prospect universe → valid contact → delivered → human reply → positive/relevant reply → conversation booked → held → qualified → export obtained → pilot agreed → client won`

## Initial test
Use a small 2×2 test rather than 12 variables at once:
- opener: problem observation vs direct result proposition;
- CTA: low-friction question vs short call.

Keep audience quality and infrastructure stable enough that differences are interpretable.

## Diagnose in order
`market → offer → list → reachability → deliverability → message → reply handling → call → commercial terms`

Do not rewrite copy because deliverability or targeting is broken.

## Evidence rule
No “benchmark” becomes an expectation until our own sends establish a baseline on this exact niche/list/infrastructure.
