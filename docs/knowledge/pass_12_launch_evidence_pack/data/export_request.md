# Export request — internal/operator version

Request the smallest useful fields first. Do not ask the client to send more personal data than the pilot needs.

Preferred fields:
- internal contact/customer ID;
- quote/opportunity ID;
- quote date;
- product/service quoted;
- quote value if available;
- opportunity status / lost reason;
- first/last name;
- phone and/or email required for approved campaign channel;
- postcode/service area signal;
- source/collection origin;
- marketing preference / opt-out / objection status;
- last contact date;
- current customer / won-job indicator;
- assigned salesperson if relevant.

Before transfer, agree the secure transfer method and whether a redacted/schema-only sample is sufficient for the first audit.
