# Metric dictionary

One definition per metric. Never let sales/reporting/delivery use different denominators.

## Acquisition — Velarqo winning clients
- **Delivered emails** = sent minus confirmed bounces/failures.
- **Human reply rate** = human replies / delivered.
- **Positive reply rate** = replies expressing relevant interest / delivered.
- **Qualified conversation rate** = firms meeting minimum fit and agreeing to substantive conversation / delivered.
- **Client win rate** = new clients / qualified sales conversations held.

## Client pilot
- **Reachable rate** = technically reachable contacts / unique contacts.
- **Eligible rate** = campaign-eligible contacts / unique contacts.
- **Delivery rate** = delivered / send attempts.
- **Reply rate** = unique repliers / delivered.
- **Positive-interest rate** = positive-interest contacts / delivered.
- **Qualification rate** = qualified contacts / delivered.
- **Booking rate** = booked contacts / delivered.
- **Attendance rate** = attended / booked.
- **Requote rate** = new quotes / attended.
- **Sale rate per delivered** = won / delivered.
- **Sale rate per attended** = won / attended.
- **Revenue per delivered contact** = attributed won revenue / delivered.

## Economics
- **Velarqo revenue per result** = contracted charge per billable result.
- **Delivery variable cost** = channel/API/tool costs directly caused by campaign.
- **Founder delivery labour** = tracked manual minutes × chosen internal hourly cost for economics analysis.
- **Gross contribution per client campaign** = Velarqo revenue − direct variable delivery cost − optional costed founder labour.
- **Client cost per attended survey** = fees attributable to campaign / attended surveys.
- **Client cost per sale** = fees attributable to campaign / won jobs.
- **Client ROAS-like ratio** = attributed revenue / campaign fees. Use cautiously: revenue is not profit.

## Cohorts
Always report outcome metrics by quote-age bucket when sample allows:
- 0–90 days
- 91–180
- 181–365
- 366–730
- 731+ days

Do not conclude that age causes differences from one small pilot; this is for learning the curve.
