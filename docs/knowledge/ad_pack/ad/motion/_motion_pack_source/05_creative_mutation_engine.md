# 05 — Creative Mutation Engine

## Goal
Generate **new motion formats** that are coherent, useful and producible, rather than merely copying a reference or adding random effects.

---

# 1. Represent every format as dimensions

```text
Narrative topology
Layout topology
Motion topology
Asset mix
Typography behavior
Transition logic
Camera model
Temporal rhythm
Material language
Density curve
```

Creativity = controlled mutation of 1–4 dimensions while preserving the others.

---

# 2. Mutation operators

## Layout mutation
- grid -> radial
- grid -> rail
- split-screen -> nested cards
- flat canvas -> 2.5D depth stack
- pages -> infinite canvas
- centered -> asymmetric editorial

## Motion mutation
- translate -> orbit
- wipe -> object morph
- hard cuts -> continuous match moves
- card expansion -> camera dive
- static diagram -> physically assembling diagram

## Asset-role mutation
- screenshots become cards
- cards become physical objects
- words become spatial labels
- photos become masked textures
- icons become nodes in a system

## Narrative mutation
- linear explanation -> mystery/reveal
- list -> accumulation
- comparison -> transformation
- tutorial -> challenge/result
- case study -> detective/diagnosis

## Temporal mutation
- constant tempo -> acceleration
- beat cuts -> continuous flow
- fast start -> slow reveal -> fast payoff

## Material mutation
- clean vector -> scrapbook
- scrapbook -> chrome/3D
- glossy tech -> newsprint/editorial
- minimal black/white -> bright modular color system

---

# 3. Hybridization

Combine two formats by assigning each a role.

Example:

**Base grammar:** F02 Progressive Diagram
**Surface grammar:** F07 Scrapbook

Result:
A diagram where nodes appear as taped paper fragments and connections are hand-drawn.

Another:

**Base grammar:** F06 Screen Tutorial
**Transition grammar:** F01 Card Constellation

Result:
App screens become cards that orbit, regroup and expand into demonstrations.

---

# 4. Novel-format recipe

1. choose a semantic goal
2. choose one base narrative grammar
3. choose one unusual layout topology
4. choose one coherent motion topology
5. choose material language
6. choose one signature mechanic
7. render a 5–8 second prototype
8. score clarity + novelty + feasibility
9. keep only if all pass

---

# 5. Signature mechanic requirement

Every new format should have one memorable behavior, e.g.:

- every new idea folds out from previous one
- all information lives on an orbit
- timeline physically bends into a diagram
- words turn into UI panels
- screenshots break into modular tiles
- cards accumulate into a final logo/shape
- diagram becomes a physical machine

Without a signature mechanic, the output is merely generic motion graphics.

---

# 6. Novelty guardrails

Reject mutations that:
- require more than 3 unrelated transition styles
- change palette/type system every scene
- use motion with no semantic reason
- sacrifice readability
- depend on unreliable generative video when deterministic motion would work
- add 3D merely for novelty

---

# 7. Distance-from-reference score

To avoid cloning, score a generated format on differences from references:

- layout difference 0–2
- motion topology difference 0–2
- material language difference 0–2
- narrative structure difference 0–2
- signature mechanic difference 0–2

A new format should generally score >= 5/10 while retaining comparable clarity and polish.

---

# 8. Creativity modes

## Conservative
Mutate 1 dimension. Good for reliable production.

## Exploratory
Mutate 2–3 dimensions. Good for new format discovery.

## Experimental
Mutate 4+ dimensions but require prototype QC before full generation.

Production should mostly use conservative formats; R&D can explore more aggressively.
