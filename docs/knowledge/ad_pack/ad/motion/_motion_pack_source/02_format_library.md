# 02 — Format Library

Each format below is a reusable grammar, not a fixed visual template.

---

## F01 — Kinetic Card Constellation
**Reference:** Sinan Karaçam

### Core mechanic
A collection of cards/images behaves like one coordinated object system.

### Beat grammar
1. establish scattered/stacked objects
2. introduce directional force
3. reorganize into fan/grid/rail
4. focus one subset
5. recombine into final composition

### Variables
- number of cards
- aspect ratios
- card content
- fan/grid/rail topology
- depth
- camera path
- palette

### Best uses
- portfolios
- “X examples”
- product collections
- visual moodboards
- category intros
- hooks

### Rendering
Primarily deterministic 2D/2.5D.

## F02 — Progressive Diagram Explainer
**References:** Tenbō Labs, The 20s Playbook, PeterStewieStartup

### Core mechanic
A conceptual diagram is built one semantic unit at a time.

### Beat grammar
1. claim/problem
2. introduce node A
3. introduce node B
4. connect them
5. add counterforce or next stage
6. zoom out to complete system
7. emphasize takeaway

### Variables
- node types
- connection types
- visual metaphor
- hierarchy
- diagram topology

### Best uses
- business concepts
- economics
- education
- systems thinking
- case studies

## F03 — Kinetic Type Argument
**References:** Djamel Haroual, Pushpendra, Bill Gates edit

### Core mechanic
Words are both language and physical objects.

### Beat grammar
1. one phrase establishes thesis
2. keyword separates/emphasizes
3. typography physically demonstrates contrast
4. visual punctuation
5. next phrase enters through continuation
6. final statement lands with reduced motion

### Mutation axes
- word scale
- baseline deformation
- text direction
- clipping
- tracking
- mask reveal
- character-by-character motion

# Format composition principle

A finished video can use one primary format plus one or two secondary mechanics.

Example:

`F02 Progressive Diagram Explainer`
+
`F03 Kinetic Type Argument` for hooks
+
`F06 Screen-in-Scene Tutorial` for evidence

This is preferable to mixing five unrelated aesthetics.
