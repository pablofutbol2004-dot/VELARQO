## Corpus routing
- Broad qualification-specific search matched **2,362 / 11,917 transcripts** using explicit qualification, fit, decision-maker, financial-capacity, scoring, screening, and disqualification language.
- Focused inspection then targeted authority, budget, timing/readiness, application design, lead scoring, false-positive/false-negative risk, downstream feedback, and qualification economics.
- Final pack contains **48 rules** across **8 categories**.

## Ownership migrations
No existing rule required deletion in this pass. Existing references to “qualified outcomes” in `funnel_mechanics`, `content_measurement`, and `offer_framing` remain because those rules own funnel/economic/offer mechanisms rather than the definition of qualification itself.

## Deliberate corrections to corpus advice
The pass does **not** encode BANT as universal truth, fixed budget/revenue/credit thresholds, “more questions = better leads,” “more friction = more intent,” non-decision-maker = automatic dead lead, or any creator's qualified-rate benchmark as a durable target.
