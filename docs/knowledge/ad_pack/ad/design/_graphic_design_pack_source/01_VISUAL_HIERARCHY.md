# Visual Hierarchy

Every composition should answer quickly:

- What do I look at first?
- What do I look at second?
- What is supporting information?
- What can I ignore?

## Hierarchy Controls

Importance can be communicated through:

- size
- weight
- contrast
- position
- whitespace
- isolation
- color
- detail

## Rules

- One dominant element per view.
- Not everything can be bold.
- Create clear separation between hierarchy levels.
- Use large scale jumps when emphasis is weak.
- Supporting content should visually recede.

### Weak hierarchy
- Headline: 36
- Subhead: 30
- Body: 26

### Stronger hierarchy
- Headline: 64
- Subhead: 28
- Body: 18

## Diagnostic

If everything feels equally important, reduce the visual weight of secondary elements before adding more emphasis to the primary element.
