# Depth and Layering

Depth can make otherwise flat compositions feel richer.

## Tools

- overlap
- layering
- blur
- scale
- foreground / background
- transparency
- gradients
- controlled shadows
- cropping beyond frame boundaries

## Rules

- Depth does not mean adding a shadow to every card.
- Overlap is often more sophisticated than default drop shadows.
- Layering should clarify hierarchy or create visual energy.
- Use type behind or in front of imagery when legibility remains strong.
