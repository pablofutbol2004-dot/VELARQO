# Reference Analysis

Do not teach the AI to copy references directly.

Extract transferable principles.

## Analyze Every Reference For

- hierarchy
- grid
- spacing
- typography
- color
- image treatment
- density
- rhythm
- composition
- motifs
- motion
- narrative
- distinctive tricks
- why it works
- when it would fail
- reusable principles

## Separate Surface From Principle

Example reference:
Huge yellow serif headline over racing photograph.

Surface:
- yellow serif
- racing image

Underlying principle:
- extreme type/image contrast
- compressed foreground/background layering
- single-color emphasis

Store the underlying principle so it can transfer to new contexts.
