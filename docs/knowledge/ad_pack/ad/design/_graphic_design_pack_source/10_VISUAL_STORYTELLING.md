# Visual Storytelling

Design should follow the narrative sequence.

## Carousel

Hook → Problem → Tension → Insight → Proof → Solution → Payoff → CTA

## Lead Magnet

Promise → Context → Framework → Examples → Implementation → Checklist → Next Action

## Landing Page

Value Proposition → Proof → Problem → Mechanism → Benefits → Examples → Objection Handling → Offer → CTA

## Rules

- Do not design each section independently.
- The visual rhythm should mirror the narrative rhythm.
- Build transitions between sections.
- Increase or decrease density deliberately.
- Use visual continuation when it encourages progression.
