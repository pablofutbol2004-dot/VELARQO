# Creative Techniques

## Oversize Something

When hierarchy feels weak, make one important element much larger.

## Crop Aggressively

Partially crop:
- letters
- images
- giant numbers
- graphic shapes

This can create scale and energy.

## Anchor to Edges

Elements touching or intentionally aligning with edges often feel more deliberate than randomly floating elements.

## Microcopy as Texture

Small metadata can add editorial sophistication:

WORKSHOP GROWTH REPORT
// 09.2026
CASE 014

Use sparingly.

## Controlled Imperfection

Editorial systems can benefit from:
- unexpected crop
- rotated label
- offset image
- oversized type
- asymmetric placement

Controlled rule-breaking is not randomness.

## Frame → Break the Frame

Build a clear grid, then let one important element escape it.

## Scale Contrast

Prefer strong contrast such as:
128 px vs 12 px
over weak contrast such as:
46 px vs 28 px

## Layer Type and Imagery

Allow imagery and typography to overlap when readability survives.

## Visual Metaphors

Prefer specific metaphors over generic literal icons.
