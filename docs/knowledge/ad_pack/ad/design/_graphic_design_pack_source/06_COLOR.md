# Color

Color should serve function before decoration.

## Primary Functions

- hierarchy
- brand identity
- state distinction
- emotion
- attention control

## Simple Color System

- Background
- Surface
- Primary text
- Secondary text
- Accent
- Optional secondary accent

## Rules

- Neutral + neutral + one accent is often enough.
- Reserve the most saturated color for important moments.
- If everything is saturated, nothing feels emphasized.
- Maintain sufficient contrast for readability.
- Use color consistently for meaning.
- Do not introduce new colors merely to make a layout feel less empty.

## 60 / 30 / 10

A useful heuristic:
- 60% dominant
- 30% secondary
- 10% accent

Treat this as guidance, not law.
