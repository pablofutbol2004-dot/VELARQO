# GRAPHIC_DESIGN_AI

A compact knowledge base for teaching an AI system to make stronger graphic-design decisions across carousels, reels, landing pages, lead magnets, ads, thumbnails, and presentations.

## Retrieval Strategy

For any design task, retrieve:

1. Universal fundamentals
2. Relevant format file
3. Brand/style system
4. Relevant reference principles
5. Message/content
6. Critique/QA rules

## Recommended Design Loop

1. Understand message and desired viewer action
2. Select narrative structure
3. Choose composition system
4. Build hierarchy
5. Set typography
6. Set spacing/grid
7. Add imagery
8. Add color
9. Add depth/decoration only if useful
10. Critique
11. Fix top three flaws
12. Final QA

## Creativity Model

Generate concepts by combining:

Narrative structure
× Composition
× Typography system
× Image treatment
× Graphic motif
× Density
× Interaction/motion

This encourages new formats without relying on random styling or direct copying.
