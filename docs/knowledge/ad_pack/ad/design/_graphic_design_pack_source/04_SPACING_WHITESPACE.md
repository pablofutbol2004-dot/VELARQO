# Spacing and Whitespace

Spacing communicates relationships.

## Proximity

- tiny space = same unit
- medium space = related units
- large space = new section

## Suggested Spacing Scale

4, 8, 12, 16, 24, 32, 48, 64, 96, 128

Use a finite scale instead of arbitrary spacing.

## Whitespace Functions

Whitespace:
- separates
- emphasizes
- creates calm
- creates premium feeling
- improves comprehension

## Rules

- Do not fill empty space merely because it exists.
- If the focal element is strong, whitespace amplifies it.
- Use larger spacing jumps between conceptual groups.
- Dense sections should be followed by calmer sections to create rhythm.
