# Grids and Alignment

Alignment is one of the fastest ways to separate amateur layouts from professional ones.

## Align To

- shared left edges
- baselines
- vertical axes
- column boundaries
- image edges
- text blocks

## Rules

- Every element should appear intentionally aligned with something.
- Random micro-offsets usually look accidental.
- Fix alignment before adding decoration.
- Use grids as constraints, not prisons.
- Breaking a grid should be deliberate and rare enough to remain visible.
