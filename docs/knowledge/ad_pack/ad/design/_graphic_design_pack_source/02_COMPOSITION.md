# Composition

Composition is the intentional distribution of visual weight.

## Sources of Visual Weight

- size
- darkness
- saturation
- detail
- faces
- isolation
- contrast
- edge position

## Composition Systems

Use deliberately:

- centered composition
- asymmetric composition
- split screen
- editorial grid
- modular grid
- hero + support
- image-dominant
- type-dominant
- diagonal movement
- Z-pattern
- F-pattern
- radial composition
- stacked vertical rhythm

## Rules

- Do not center everything simply because it is safe.
- Asymmetry can create sophistication and energy.
- Balance does not require symmetry.
- Anchor key elements to strong edges, columns, or visual axes.
- Crop intentionally when scale or energy benefits from it.
- Let one element break the grid occasionally if the exception creates emphasis.
