# Lead Magnet and PDF Design

A lead magnet should feel like a designed editorial object, not a document with a decorative cover.

## Core Components

- strong cover
- contents / navigation
- chapter openings
- clear hierarchy
- callout boxes
- pull quotes
- numbered frameworks
- diagrams
- examples
- page rhythm
- page numbers
- consistent running headers / footers

## Rules

- Alternate text-heavy and visual pages.
- Use section dividers.
- Make frameworks visually scannable.
- Turn repeated concepts into reusable visual components.
- Preserve generous margins.
