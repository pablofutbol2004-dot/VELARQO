# Reels and Motion Graphics

Graphic design in motion is temporal composition.

## Core Rules

- Optimize for readability in under a second.
- Use fewer words.
- Use larger type.
- Animate hierarchy.
- Avoid several competing movements at once.
- Synchronize emphasis with narration.
- Keep critical elements away from UI zones.
- Use kinetic typography selectively.
- Change composition when the idea changes.
- Motion should explain or emphasize meaning.

## Mental Model

Motion is hierarchy over time.

## Useful Motion Behaviors

- progressive reveal
- scale emphasis
- mask reveal
- tracking changes
- object follow
- text replacement
- diagram build
- emphasis pulse
- camera crop
- hard cut for conceptual shift

## Avoid

- motion for motion's sake
- excessive easing tricks
- constant zooming
- decorative particles with no function
