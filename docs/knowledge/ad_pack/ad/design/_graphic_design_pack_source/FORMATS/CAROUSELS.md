# Carousel Design

## Core Rules

- The cover must interrupt the feed.
- One dominant message per slide.
- Use large typography when appropriate.
- Preserve safe margins around platform UI.
- Keep identity consistent while varying layouts.
- Information density can rise after the hook.
- Use occasional pattern interruption.
- The ending should feel visually conclusive.
- Avoid repeating one template for every slide.

## Visual Continuation

Use arrows, crops, lines, or incomplete visual structures to make the next slide feel like a continuation.

## Rhythm

Alternate:
- statement slides
- proof slides
- diagrams
- screenshots
- image-led slides
- dense explanation
- sparse emphasis

## Failure Modes

- every slide identical
- tiny text
- weak cover hierarchy
- excessive decoration
- no narrative progression
