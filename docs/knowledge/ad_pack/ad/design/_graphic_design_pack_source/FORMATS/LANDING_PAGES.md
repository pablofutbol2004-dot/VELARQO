# Landing Page Design

## Core Priorities

- above-the-fold clarity
- one dominant CTA
- scannability
- section differentiation
- responsive hierarchy
- visual proof near claims
- readable line width
- repeated CTA at logical moments
- clear section rhythm
- conversion over artistic cleverness

## Information Density Rhythm

Example:

Huge hero
→ Dense social proof
→ Simple benefit statement
→ Detailed feature section
→ Large testimonial
→ Comparison
→ CTA

## Rules

- Alternate dense and sparse sections.
- Use proof close to major claims.
- Keep CTA language consistent.
- Avoid giant walls of text.
- Establish a clear visual anchor per section.
