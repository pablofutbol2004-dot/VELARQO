# Design Diagnosis

Teach the AI to identify the problem before changing the design.

## If It Looks Boring

Try:
- stronger scale contrast
- asymmetry
- stronger crop
- better image
- fewer elements
- clearer focal point

## If It Looks Chaotic

Try:
- fewer type styles
- fewer colors
- stronger grid
- better alignment
- more whitespace
- less decoration

## If It Looks Cheap

Try:
- fewer effects
- stronger typography
- more whitespace
- better photography
- simpler palette
- fewer gradients and shadows

## If It Looks Generic AI

Look for:
- glassmorphism everywhere
- purple/blue glowing gradients
- floating UI cards
- meaningless arrows
- abstract 3D blobs
- generic corporate illustration
- excessive rounded rectangles

Remove them unless they serve a clear concept.
