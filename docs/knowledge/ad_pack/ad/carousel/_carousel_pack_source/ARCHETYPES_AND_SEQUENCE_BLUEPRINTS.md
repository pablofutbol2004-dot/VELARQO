# Carousel Archetypes and Sequence Blueprints

These are **architectures**, not visual templates. The AI should choose one because it matches the content objective, then vary the actual design.

---

## Archetype 1 — Contrarian / Reframe Essay

### Best for
- thought leadership;
- service positioning;
- opinion;
- reframing a common belief.

### Source patterns
Seen in `realjoemutuku`, `drex.dsgn`, `prclarity.co`, `softriver.co`, `architecture_templates`, `peter.visuals`.

### Sequence blueprint
1. **Contrarian claim** — challenge an accepted belief.
2. **Clarify the mistake** — what people currently think/do.
3. **Consequence** — why the old frame fails.
4. **Mechanism** — what is actually happening.
5. **New frame** — replacement belief.
6. **Example / analogy / proof**.
7. **Application** — what to do differently.
8. **Compressed conclusion** — quotable residue.
9. Optional CTA.

### Core continuation engine
Each slide removes one objection or deepens the reframe.

### Main failure mode
Repeating the same provocative claim for 8 slides without adding mechanism or evidence.

## Archetype 2 — Framework / System Breakdown

### Best for
- named methods;
- playbooks;
- educational content;
- lead magnets;
- systems thinking.

### Source patterns
`growithalex`, `kallawaymarketing`, `thebami_`, `peter.visuals`, `growthwithhardik`.

### Sequence blueprint
1. **System promise / name**.
2. **Problem the system solves**.
3. **Map of components**.
4–N. **One component per slide**.
N+1. **Synthesis / how components interact**.
N+2. Optional **application example**.
N+3. **CTA / downloadable version / next action**.

### Core continuation engine
Structured incompleteness: the viewer knows there are more parts to reveal.

### Main failure mode
Naming obvious advice as a “framework” without increasing clarity or usefulness.

## Archetype 3 — Tutorial / Process

### Best for
- design technique;
- software workflow;
- detailing procedure;
- practical how-to.

### Source patterns
`iamlorereis`, `idcustom_automotive`, `drivelinestudios.lk`, `aiwithanushka`.

### Sequence blueprint
1. **Outcome / task cover**.
2. **Starting state / prerequisites**.
3. Step 1.
4. Step 2.
5. Step 3.
6. Step 4.
7. **Result / transformation**.
8. Optional **shortcut / mistake / variation**.
9. CTA or save prompt.

### Core continuation engine
Visible progress toward a finished result.

### Main failure mode
Showing steps without enough visual evidence to replicate them.

## Archetype 4 — Do / Don’t Contrast

### Best for
- mistakes;
- quality differentiation;
- corrective education;
- product/service expertise.

### Source patterns
`drivelinestudios.lk`, `growthwithhardik`, typography/design teaching.

### Sequence blueprint A — repeated pairs
1. Cover.
2. Don’t / Do #1.
3. Don’t / Do #2.
4. Don’t / Do #3.
5. Don’t / Do #4.
6. Final principle / CTA.

### Sequence blueprint B — split-panel slides
Each body slide contains:
- bad behavior;
- consequence;
- better behavior;
- short rationale.

### Core continuation engine
Comparison creates immediate clarity and anticipation of the next error.

### Main failure mode
Moralizing without explaining the mechanism behind the “do.”

---

## Archetype 5 — Mistakes / Diagnostic List

### Best for
- design;
- marketing;
- local service education;
- “why your result is weak” content.

### Source patterns
`uxintace`, `prestigeautospamia`, `growthwithhardik`.

### Sequence blueprint
1. **Specific mistake promise**.
2. Mistake #1 + consequence + correction.
3. Mistake #2 + consequence + correction.
4. Mistake #3 + consequence + correction.
5. Mistake #4 + consequence + correction.
6. **Pattern behind the mistakes**.
7. **Simple diagnostic checklist**.
8. CTA.

### Core continuation engine
Self-diagnosis: the viewer wants to know whether they commit the next mistake.

### Main failure mode
Generic mistakes the target audience already knows.

## Archetype 6 — Reference Library / Cheat Sheet

### Best for
- grid types;
- layout types;
- business frameworks;
- hook families;
- examples;
- resources.

### Source patterns
`expert.pitch`, `peter.visuals`, `growithalex`, `growthwithhardik`, `uxintace`.

### Sequence blueprint
1. **Collection promise** — number + category.
2–N. **One reference unit per slide**, consistently structured.
N+1. **Selection rule / when to use what**.
N+2. Optional CTA.

### Each unit should ideally include
- name;
- definition;
- when to use;
- example;
- limitation or selection cue.

### Core continuation engine
Collection completion + reference value.

### Main failure mode
A list that is large but not decision-useful.

---

## Archetype 7 — Evidence / Research Explainer

### Best for
- data;
- studies;
- technical topics;
- evidence-led authority.

### Source patterns
`dr.longevity`, `thebrainlabco`, `mockiro`.

### Sequence blueprint
1. **Surprising conclusion / research question**.
2. **What was studied / source context**.
3. **Main result**.
4. **Comparison / scale / benchmark**.
5. **Alternative explanation or caveat**.
6. **Application**.
7. **Conclusion**.

### Core continuation engine
Evidence accumulation.

### Main failure mode
Using scientific-looking design to imply certainty that the source material does not support.

### Generation constraint
Claims, numbers, causal language, and citations must come from verified source material. Do not invent “studies” for visual authority.

## Archetype 8 — Story / Case Narrative

### Best for
- brand stories;
- customer stories;
- founder stories;
- before/after identity changes;
- case studies.

### Source patterns
`sun.yi`, `eksdesigns`, `rend.more`, `thebami_`.

### Sequence blueprint
1. **Hook / paradox / intriguing setup**.
2. Context.
3. Inciting event.
4. Complication.
5. Turning point.
6. Result.
7. Meaning / reframe.
8. Connection to audience.
9. Optional brand/CTA bridge.

### Core continuation engine
Unresolved outcome + state change.

### Main failure mode
A diary recap with no shift, relevance, or meaning.

## Archetype 9 — Example Roundup / Teardown

### Best for
- copywriting examples;
- packaging;
- campaigns;
- competitors;
- inspiration with analysis.

### Source patterns
`sodigitalcopystudio`, `yaw_majesty`.

### Sequence blueprint
1. **Category promise**.
2. **Selection criterion** — why these examples matter.
3–N. Example card:
   - example;
   - what works;
   - mechanism;
   - takeaway.
N+1. **Cross-example pattern**.
N+2. **Viewer question / CTA**.

### Core continuation engine
Curiosity about the next example + comparative learning.

### Main failure mode
Moodboard dumping without analysis.

## Archetype 10 — Visual Portfolio / Mood Sequence

### Best for
- photography;
- architecture;
- cars;
- art direction;
- brand worlds;
- product visuals.

### Source patterns
`michaelboegl`, `heythisiskazu`, `ksn.dz`, `rend.more`.

### Sequence blueprint
This is not text-defined. Build a **visual sequence curve**.

Possible structure:
1. Hero / establishing image.
2. Alternate scale.
3. Detail.
4. Human or environmental context.
5. Texture / object.
6. Contrast image.
7. Resolution / strongest closing image.

For longer sets, repeat scale changes while preserving theme.

### Core continuation engine
Visual curiosity, aesthetic pleasure, variation in scale, and coherent mood.

### Main failure mode
Ten individually attractive images with no curation logic.

### Important rule
Do not add explanatory copy merely to make the carousel “educational.” The visuals may be the value.

`prestigeautospamia`, `idcustom_automotive`, `drivelinestudios.lk`.

2. Business/service as solution.

### Sequence blueprint B — diagnostic education
1. Local/seasonal problem.
2. Mistake #1.
3. Mistake #2.
4. Mistake #3.
5. Service relevance + CTA.

Final slide. Brand standard / visit CTA.

### Main failure mode
Turning every slide into an ad. Educational or entertaining value should precede conversion.

# Sequence primitives

Archetypes can be recombined using these primitives.

## Primitive A — Open Loop
State something incomplete that can be resolved later.

Use sparingly. If every slide is a cliffhanger, the carousel feels manipulative.

## Primitive B — Escalation
Increase:
- stakes;
- specificity;
- consequence;
- novelty;
- emotional intensity.

## Primitive C — Contrast
Before/after, wrong/right, myth/reality, weak/strong, product/brand, generic/specific.

## Primitive D — Enumeration
A numbered sequence creates structural certainty and completion motivation.

## Primitive E — Reveal
Show the answer after sufficient setup.

## Primitive F — Example
Convert abstraction into something concrete.

## Primitive G — Proof
Add screenshot, chart, result, real-world example, or source evidence.

## Primitive H — Compression
Turn a multi-slide explanation into a final diagram, checklist, or memorable line.

## Primitive I — Callback
Reference an earlier image, phrase, or claim so the ending feels designed rather than merely stopped.

## Primitive J — CTA Bridge
Connect the learned idea directly to the next step.

# Choosing an archetype

Use this decision rule:

- **Need to change a belief?** → Contrarian / Reframe Essay.
- **Need to teach a reusable method?** → Framework / System.
- **Need to show how to do something?** → Tutorial / Process.
- **Need to correct behavior quickly?** → Do / Don’t or Mistakes.
- **Need reference/save value?** → Cheat Sheet / Library.
- **Need to explain evidence?** → Research Explainer.
- **Need emotional/brand connection?** → Story / Narrative.
- **Need to teach through examples?** → Example Roundup / Teardown.
- **Need to showcase taste?** → Visual Portfolio.
- **Need audience bonding?** → Identity / Relatable.
- **Need local leads?** → Problem → Solution Local Business.

Do not choose based on which template is easiest to render.

# Hybrid architectures

The strongest new formats can come from hybridizing compatible archetypes.

Examples:

### Research × Story
- surprising claim;
- human scenario;
- evidence;
- mechanism;
- practical takeaway.

### Teardown × Tutorial
- show a real example;
- identify what works/fails;
- rebuild it step by step.

### Portfolio × Essay
- one strong image per slide;
- minimal line of argument;
- visuals carry emotional meaning.

### Mistakes × Case Study
- “3 places this workshop is losing leads”;
- one real funnel stage per slide;
- evidence screenshot;
- proposed fix;
- expected behavior change.

### Reference Library × Decision Tree
- show options;
- then teach how to choose among them.

Hybridization is a primary route to **novel carousel formats** without arbitrary weirdness.
