# Business Knowledge OS — Chat Export State

This package captures the business-knowledge project created in this chat through **Pass 14**.

## Original goal
Build a business-agnostic knowledge base / operating system for becoming a successful solo founder with heavy AI leverage, while using **Velarqo — UK windows & doors database reactivation** as the first live application.

Core epistemic rule used throughout:

> Own data and experiments > direct customer artifacts and statements > current primary sources > independent market evidence > vendor claims > books/practitioner content > founder intuition.

The system is designed so external knowledge is eventually replaced by proprietary evidence from real outreach, installer conversations, exports, pilots, downstream sales and cash collection.

## Current Velarqo working thesis
- Market: UK residential window & door installers.
- Wedge: recover qualified opportunities from old/lost quotes already paid to generate.
- Sell the economic outcome, not “AI automation.”
- Current founder-pilot commercial hypothesis: low/no setup fee, performance-based booked-survey pricing, bounded pilot, transparent billable definition. This remains a test, not validated truth.
- Pilot evidence should track the full downstream path: eligible → delivered → reply → positive → qualified → booked → attended → requote → won → cash.
- Use holdouts/baselines where practical to distinguish attribution from incremental lift.

## Current evidence gates
1. **Outbound readiness gate** — 20 controls (Pass 13)
2. **Acquisition factory integrity gate** — 30 controls (Pass 14)
3. **Client/homeowner data & pilot readiness gate** — 50 controls (Pass 12)
