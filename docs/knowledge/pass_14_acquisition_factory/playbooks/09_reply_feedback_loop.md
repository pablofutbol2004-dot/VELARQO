# 09 — Reply and learning loop

## Reply classes

- positive_interest
- research_only_interest
- referral_to_other_person
- timing_later
- not_interested
- already_solved
- wrong_person
- wrong_company_fit
- objection_price
- objection_trust
- objection_existing_supplier
- unsubscribe/object
- complaint
- auto_reply
- bounce

## Immediate actions

`unsubscribe/object` → global suppression before any further send.
`complaint` → suppress + manual review.
`wrong_person` → update role map; do not mark company uninterested automatically.
`wrong_company_fit` → feed qualification rule.
`already_solved` → tag alternative/current process.

## Weekly learning

Every week update:
- ICP reason codes
- contact-source performance
- named vs generic performance
- verification provider accuracy
- reply taxonomy
- offer-angle performance
- downstream conversation/export rate

Do not optimize on reply rate alone.
