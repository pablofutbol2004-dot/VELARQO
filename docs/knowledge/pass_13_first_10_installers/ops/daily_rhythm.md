# Daily founder rhythm

## Block 1 — replies first
Handle positive, ambiguous, privacy/legal and negative replies before prospecting more names.

## Block 2 — calls / follow-up
Run booked calls and complete evidence capture immediately afterwards.

## Block 3 — next prospect batch
Research and qualify only enough prospects to keep the experiment moving.

## Block 4 — evidence + decision
Update the daily board. Write the current constraint in one line.

## End-of-day questions
1. Where did the funnel lose the most qualified opportunity today?
2. Is that loss caused by market, list, reachability, message, reply handling, call, export friction, or offer?
3. What evidence supports that diagnosis?
4. What is the smallest next test?
5. What should *not* change tomorrow so the test remains interpretable?
