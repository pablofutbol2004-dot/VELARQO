# First-10 acquisition decision rules

Do not use universal cold-email benchmarks as truth. Use our funnel and qualitative evidence.

## If delivery/bounce is bad
Stop increasing volume. Fix list/contact infrastructure before changing offer copy.

## If delivery is healthy but relevant replies are near zero
Inspect, in order:
1. ICP/list fit;
2. whether the problem is recognized;
3. offer/mechanism clarity;
4. message/CTA.

## If replies happen but calls do not
Reply handling / CTA / scheduling friction is the likely layer to inspect.

## If calls happen but no exports are shared
Potential causes:
- trust;
- data accessibility;
- weak pain;
- poor pilot framing;
- compliance fear;
- no actual backlog.

Ask which one explicitly.

## If exports arrive but are unusable
That is product/market evidence, not an onboarding nuisance. Quantify the reason: missing statuses, poor provenance, no contactability, tiny backlog, old age, mixed bought leads, etc.

## If prospects want the result but not performance pricing
Test alternative commercial structures. Do not infer the problem itself is invalid.

## If repeated calls reveal no meaningful dormant inventory
Reevaluate the wedge or segment. This is a core assumption failure.

## If 10 calls show strong backlog + weak follow-up + exportability
Do not build more theory. Push the best-fit prospect through Pass 12.
