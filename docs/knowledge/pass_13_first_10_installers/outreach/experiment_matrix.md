# Outbound experiment matrix

The goal is not to test eight variants simultaneously on a tiny sample. These are four **angles** to stage sequentially as evidence accumulates.

## Test order
1. Start A vs B if the immediate objective is pilot acquisition.
2. Use C/D when the key constraint is customer knowledge or skepticism.
3. Keep the audience definition stable enough to compare.
4. Judge on relevant reply → held conversation → export → pilot progression, not copy aesthetics.
