# Redacted export request after a strong-fit call

Send the smallest useful sample first. Do not ask for the full homeowner database before the relationship and controls justify it.

## Preferred sample
20–50 historical unclosed quote records, redacted where possible for the initial audit.

Useful fields:
- record ID;
- quote/enquiry date;
- product/service;
- quote value/range if available;
- status/lost reason;
- source/channel;
- number/timing of previous follow-ups;
- sold/not-sold indicator;
- marketing/opt-out status if stored;
- data-source/capture route.

For the first structural audit, names, phone numbers and emails are not required unless a later lawful/contracted stage specifically needs them.

Also request:
- screenshot/text of the original website form/privacy/marketing wording where relevant;
- list of systems used (CRM/quoting/inbox/etc.);
- how suppressions/opt-outs are stored;
- explanation of any bought/shared lead sources mixed into the dataset.

Route any real homeowner data into the Pass 12 client-data workflow, not ordinary prospecting files.
