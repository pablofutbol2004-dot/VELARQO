# Business Knowledge Pass 13 — First 10 Installers Launch Pack

Purpose: convert the existing knowledge/evidence system into a bounded founder-led acquisition sprint whose output is **10 real installer conversations, 3 usable exports, and the first pilot candidate**.

This pack does not invent outreach benchmarks. It measures our own funnel.

## Definition of success
The sprint is successful if it produces evidence, not merely sends:
1. 10 installer conversations with structured notes;
2. 3 redacted exports or equivalent concrete data samples;
3. at least 1 prospect that clears commercial/data/capacity screening strongly enough to enter the Pass 12 Client-1 gate;
4. explicit evidence about why prospects did not advance.

## Operating principle
Diagnose acquisition in order:
`market → offer → list → contactability → deliverability → message → reply handling → conversation → export → pilot`

Do not rewrite copy when the broken stage is upstream.
